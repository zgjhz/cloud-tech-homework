Локальные лабораторные для ДЗ 2, 3 и 5; CI/CD ДЗ 6 выполняется в GitLab.com.
ДЗ 1 и 4 не входят в проект. Каждая работа выполняется и коммитится отдельно.

## Порядок

1. [Подготовка окружения](docs/local-setup.md).
2. ДЗ 2 — Docker Compose, HTTP entry point и PostgreSQL (следующий этап).
3. ДЗ 3 — Kubernetes frontend/backend (запланировано).
4. ДЗ 5 — RabbitMQ, маршрутизация и DLQ (запланировано).
5. ДЗ 6 — GitLab CI/CD и Container Registry (запланировано).
